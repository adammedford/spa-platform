`Observed.SettledCountAsync` now waits for the log to stop growing before taking the count, and the
reason is in its doc comment. Any later row that reads a rule id should take its count the same way.

**Fixed (6).**

1. **`RegistryRejectionTests` — an assertion that could not fail, on the row the class exists for.**
   The class's stated design is that every row publishes "two changes: the one the row names, and a
   perfectly legitimate one beside it", so that a validator which rejected the bad entry and applied
   the good one would be caught. `Benign()` writes `app1["csp"]`, and the forbidden-CSP row's spoil

   document. Fixed by appending `*` to the benign directive instead of replacing it, so the document
   now carries `img-src: [benign, "*"]`. **Mutation-verified** (CODING_STANDARDS.md -> "Mutate, do
   not infer"): replacing the `*` with a second legitimate source made the document valid, the poll

   does reach the published document now. Reverted; 89 of 89 green.
2. **`MethodAndLimitTests` — an assertion that could not fail, and a comment that outran it.**
   `Assert.DoesNotContain("xxxx", response.StatusLine)` cannot fail: a status line never carries a
   request header's value. The comment beside it claimed "no stage ran to log anything of it", which
   nothing checked. Replaced with a sweep of the harness log for the 40 KB value, guarded by
   `Assert.NotEmpty(Harness.Log.Lines)` the way `CanarySweep.Assert` guards its own.
3. **`EmbeddingHeaderTests` — `frame-ancestors` was not pinned to the value its row names.** The

4. **`MethodAndLimitTests` — a copy of fixture data.** The `CONNECT` target was the literal

5. **`HostRefusalTests` and `ReservedPathTests` — a copy of a contract value.** Both typed
