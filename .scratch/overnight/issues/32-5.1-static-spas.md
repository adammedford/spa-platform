- API routes `/whoami` (GET) and `/echo` (POST) come from the 5.3 row. The page shows only the status of the echo response, so an upstream's echo of the request never sits in the DOM.
- A 401 on the session or an API call navigates to `/bff/login`. This is the step that makes F-04's "next navigation shows the provider's login page" happen.
