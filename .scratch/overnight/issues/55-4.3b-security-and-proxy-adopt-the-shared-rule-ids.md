# 55: 4.3b — The security and proxy stages read the shared rule ids
**Task:** 4.3b
**Owner:** ws4-proxy
**Blocked by:** 52
**Status:** resolved

**What to build:** `Platform.Abstractions.RuleIds` now holds the twelve ids from
`contracts/request-gate.md` as constants (integrator's decision, ADR-0015, 14 October 2026).
Workstream 4 has the oldest copies of them: `Platform.Security`'s own constants, and the private
`const string Rule` in `src/Platform.Proxy/UnknownApi.cs`. Read the shared constants instead.

| Rule ids | Where its copy lives today |
| --- | --- |
| `path.invalid`, `path.reserved`, `gate.cookie-name`, `gate.fetch-site`, `gate.origin`, `gate.navigation`, `gate.method` | `src/Platform.Security` |
| `csrf.token` | `src/Platform.Security/PlatformAntiforgery.cs` |
| `api.unknown` | `src/Platform.Proxy/UnknownApi.cs` |

Nothing about the behaviour changes: the strings are identical, and
`tests/Platform.Abstractions.Tests/RuleIdsTests.cs` is what keeps them identical to the contract.
Note that `path.invalid` and `path.reserved` are raised by **two** owners — the request gate and the
asset endpoint — which is exactly why one spelling now lives in one place.

Contracts: `contracts/request-gate.md` -> Rule ids, which now names the constants and the test.

## Acceptance
- [ ] Neither `src/Platform.Security` nor `src/Platform.Proxy` declares a rule id string of its own
- [ ] Every id is set from `Platform.Abstractions.RuleIds`, at the same chokepoints task 4.3a used
      (`RequestGate.RefuseAsync`, `AntiforgeryStage.InvokeAsync`, `UnknownApi.WriteAsync`)
- [ ] The Warning lines still log the same strings: the log value and the feature value come from one
      constant, as 4.3a left them
- [ ] `MethodAllowlist.cs` keeps its `gate.method` behaviour unchanged. Ticket 53 owns the stage-1
      gap; this ticket is a rename, not a fix for it
- [ ] The tests task 4.3a added still pass unchanged
- [ ] `dotnet test --project tests/Platform.Security.Tests` and `--project tests/Platform.Proxy.Tests`
      are green
- [ ] Writes only `src/Platform.Security`, `src/Platform.Proxy` and their test projects

## Why this status
One owner, no behaviour change, no contract change.

**Blocked by 52 only to avoid a conflict**, not for correctness: ticket 52 touches the same call
sites. Land #23 first, then this.

Do **not** also move `ProxyTimeout.MaximumTimeoutSeconds`. ADR-0015 decided it stays in
`Platform.Proxy`: it is measured from a pinned YARP, and `Platform.Abstractions` must not carry a
number whose truth depends on a dependency version.
